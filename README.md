# Life & Health Planner

เว็บแอปภาษาไทยสำหรับวางแผนชีวิต บันทึกเวลาจริง ออกกำลังกาย โภชนาการ และข้อมูลร่างกาย

## ความสามารถ
- ภาพรวมกิจกรรมวันนี้จากข้อมูลจริง
- ตารางชีวิตแบบวันที่และเวลาเริ่ม/สิ้นสุด พร้อม CRUD, สถานะ และเตือนเวลาทับซ้อน
- บันทึกเวลาจริงแบบวันที่และระยะเวลา
- แผนออกกำลังกายตัวอย่างพร้อมวิธีทำและบันทึกผล
- บันทึกอาหาร ปริมาณ พลังงาน และสารอาหารหลัก
- ประวัติข้อมูลร่างกายและ BMI ในฐานะตัวชี้วัดคัดกรอง
- รายงานตามสัปดาห์ เดือน ปี และช่วงวันที่กำหนดเอง
- ตั้งค่าเป้าหมาย พร้อมส่งออก/นำเข้าข้อมูล JSON และลบข้อมูล

## เริ่มใช้งาน
ต้องมี Node.js 18 ขึ้นไป

    npm install
    npm start

เปิด http://localhost:3000 และ health check ที่ http://localhost:3000/health

## ทดสอบ
    npm test

ใช้ Node.js built-in test runner ทดสอบการคำนวณเวลา ช่วงวันที่ overlap การรวมรายงาน โภชนาการ และ BMI

## ข้อมูลและความเป็นส่วนตัว
ใช้ LocalStorage ของเบราว์เซอร์และอุปกรณ์ปัจจุบัน ไม่มีบัญชีผู้ใช้หรือการซิงก์ข้ามอุปกรณ์ ไม่มีการเรียก AI API หรือส่งข้อมูลสุขภาพออกนอกระบบ ควรส่งออกไฟล์สำรองเป็นระยะ เป้าหมายสารอาหารเป็นค่าเริ่มต้นตัวอย่างที่แก้ไขได้ ไม่ใช่คำแนะนำเฉพาะบุคคล

ข้อมูลเดิมจาก key lhp_ จะถูกย้ายเข้า lhp_app_v2 เมื่อเปิดเว็บครั้งแรก โดยไม่ลบ key เดิม
